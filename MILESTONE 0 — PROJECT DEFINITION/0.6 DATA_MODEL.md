# Voryn — Data Model

## Project
AI Lead-to-Appointment Automation

## Milestone
0.6 — Define Data Model

## Purpose

The data model defines the information that must be captured, generated, stored, and tracked throughout the lead-to-appointment process.

## 1. Lead Information

- lead_id
- name
- email
- phone
- company
- service
- budget
- timeline
- message
- created_at
- updated_at

## 2. AI Analysis

- ai_summary
- business_type
- intent
- missing_information
- ai_confidence

## 3. Qualification

- lead_score
- lead_classification

Initial classifications:

- HOT
- WARM
- NEEDS_INFORMATION

## 4. Workflow Status

Initial statuses:

- NEW
- ANALYZED
- QUALIFIED
- CONTACTED
- FOLLOW_UP
- BOOKED
- CLOSED

## 5. Follow-Up

- follow_up_required
- next_follow_up
- follow_up_count

## 6. Appointment

- appointment_date
- appointment_time
- calendar_event_id
- appointment_status

## Data Sources

### Customer-provided
- Name
- Email
- Phone
- Company
- Service
- Budget
- Timeline
- Message

### AI-generated
- AI summary
- Business type
- Intent
- Missing information
- AI confidence

### System-generated
- Lead ID
- Status
- Lead score
- Classification
- Timestamps
- Follow-up information
- Appointment information

## Design Principle

The data model should allow the system to track a lead from initial submission through analysis, qualification, communication, follow-up, and appointment.

## Implementation Note

The final storage technology has not yet been selected.

The data model is technology-independent at this stage.
